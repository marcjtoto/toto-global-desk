# Editorial standards

ToTo Global Desk is an evidence newsroom. These rules apply to every desk.

## Labels

| Label | Meaning |
| --- | --- |
| Verified | Primary documents, official records, or multiple independent reliable sources |
| Strongly Supported | Strong evidence, one key confirmation still missing |
| Reported / Unconfirmed | Credible claims, not independently verified |
| Disputed | Reliable sources conflict, or a denial is unresolved |
| False / Misleading | Evidence contradicts the claim |
| Unknown | Not enough to conclude |

## Source types

- **Primary:** court filing, law, official record, contract, verified original media, on-the-record interview
- **Secondary:** established newsroom, academic work, reputable NGO
- **Lead only:** social post, anonymous message, partisan blog, undated video

A social post is a lead, not proof.

## Language

Do not call something corruption, fraud, scam, or crime without the matching record. Use alleged / according to / records reviewed indicate / could not independently verify.

DEMO content must stay labeled DEMO. Fictional names in templates are not real subjects.

## Right of reply

Before serious criticism of a named subject: numbered questions, a deadline, a fair account of the reply. Use “did not respond by publication time” unless they explicitly refused.

## Safety

No hacking, doxxing, impersonation, or illegal collection. Protect private people, minors, and victims. This contact page is not anonymous and not encrypted.
